AUTHENTICATION / AUTHORIZATION / TLS

Security center

Gambaran perlindungan API berdasarkan Modul Praktikum 06.

01

API Key

Header x-api-key diperlukan ketika login. API key bukan pengganti identitas pengguna.

02

Bearer Token

Token opaque acak berlaku 15 menit dan dapat dicabut melalui logout. Disimpan sebagai hash di memori server.

03

Role-based access

Reader dapat membaca; admin dapat mengubah koleksi. Penolakan akses dilakukan melalui middleware Express.

04

HTTPS / TLS

Komunikasi menggunakan sertifikat lokal self-signed. Konfigurasi ini hanya untuk komputer sendiri.
